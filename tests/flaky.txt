# Quarantined checks: the single list of checks that fail intermittently.
#
# A check that fails intermittently goes here and is turned off until it is
# fixed. Quarantined checks are skipped, not run and ignored:
#   - a whole suite: tests/run-suites.sh skips it and prints "SKIP (flaky): <suite>"
#   - a section: tests/lib/sections.sh (and the scheduler in test_probe_refresh.sh)
#     skips it and prints "SKIP (flaky): <suite>:<section>"
#   - a ci:<name> entry: the CI step that names it reports but does not enforce
# CORTADO_RUN_FLAKY=1 runs quarantined suites and sections anyway, to work on a fix.
#
# Each entry is tracked for a fix in a GitHub issue, named in its evidence.
# Fixing an entry means deleting its line in the pull request that fixes it.
# tests/test_run_suites.sh fails when an entry names a suite, section or CI
# check that no longer exists, so stale entries are noticed.
#
# One entry per line, fields separated by two or more spaces:
# <suite>[:<section or check>]  <date first seen>  <evidence: run id / PR>  <one-line symptom>
